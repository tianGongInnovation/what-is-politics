## 一、有什么用处

帮你把「政治」这个词从云端拽回地面，看清它跟你有什么关系。具体能做四件事：

1. **讲清定义**：政治到底是什么（五个字：关系和态度），以及这个结论是怎么用「化简法」推出来的；
2. **打通名词**：政治觉悟、政治能力、政治问题、政治基础……这些词用「关系和态度」一套就通；
3. **用回生活**：夫妻相处、借钱交友、职场上下级，处处是政治，教你把态度和关系分开管理；
4. **给方法论**：为什么政治理论是「最系统的成功学」，普通人怎么学、怎么用。

适合这些人用：想看懂新闻和官方用语的普通人、刚接触政治理论的学生、需要处理人际与职场关系的职场人、做思想教育工作的基层工作者。

## 二、为什么要用它

讲政治的书和课不少，问题在两头：要么端着学术腔、文件腔，读完还是不知道跟自己有什么关系；要么讲成权术、厚黑，把人带偏。这个专家的价值在于：

- **一句话落到地**：「政治 = 关系和态度」，五个字，拿去就能解释各种政治名词；
- **有推导、有证据链**：从孔子、亚里士多德、孙中山、毛泽东、邓小平到江泽民、习近平，一条脉络串下来，不是拍脑袋；
- **讲生活不讲官场**：学政治不为当官，为过日子——夫妻、朋友、同事，都是政治现场；
- **有尺度**：只讲事实和道理，不评论现实政治事件与人物，不做政治站队。

## 三、怎么用

安装后，在 WorkBuddy 的「专家」里找到「什么是政治」，直接问就行。三个推荐的开场问法：

- 政治到底是什么？怎么定义的？
- 政治和我有什么关系？
- 一个人如何提高政治能力？

**怎么问效果最好**：把你具体的场景说清楚（跟谁的关系、卡在哪件事上），越具体，给出的分析越能用。想深入可以追问「这个词用政治解释得通吗」「我这件事该怎么处理」。
