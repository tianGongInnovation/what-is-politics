# 梁衡《政治姓公不姓私》——反方观点备考

> **重要说明（先读）**：本文收录的是与本专家核心立场**相左**的观点，供参考交流、知己知彼之用。收录不代表认同。本专家的立场是"政治需要泛化，不怕泛化"（见《白话政治（精修）》），梁文是"泛化"定义最主要的学理挑战，读懂它，才能把我们的立场讲得更稳。

## 出处与背景

- 作者：梁衡（资深报人、政论作家）
- 载体：2012 年前后发表于《光明日报》的政论文章，核心命题为"政治姓公不姓私"
- 性质：针对社会上"什么都是政治"现象的批评文章

## 核心论点（摘其大意）

1. **政治是公共事务，不是私人事务**。"政"是众人之事、公事；把私人生活、个人小事都往政治上扯，是对政治的误用。
2. **政治要防止泛化**。什么都政治化，会把真正重要的公共政治议题稀释掉，也会让普通人背上不必要的思想负担。
3. **私事归私事，公事归公事**。个人柴米油盐、家长里短不属于政治范畴，不应要求人人时时"讲政治"。

## 与我们观点的分歧在哪

| 分歧点 | 梁文的立场 | 本专家的立场 |
|---|---|---|
| 政治的范围 | 只覆盖公共事务（姓公） | 覆盖一切人与人的关系与态度（公私皆有） |
| "泛化"的评价 | 泛化是病，要防 | 泛化正是目的——恰恰是政治被看得太窄，才更需要泛化回生活 |
| 普通人学政治 | 不必时时讲政治 | 人人日用而不知，学了能直接改善自己的日子 |

## 被质疑时的回应口径

1. **先承认对方合理处**：防止"乱扣政治帽子"、防止形式主义地讲政治，这个警惕是对的，我们也反对。
2. **再指出定义层级不同**：梁文说的是"政治运动式、口号式的政治化"，我们说的是"政治作为一种认识方法回到日常"——前者是把私事上纲上线，后者是把方法下沉到生活，方向正好相反。
3. **用定义收口**：政治 = 关系和态度。态度与关系无处不在，所以政治无处不在；这不是扩大化，而是还原它本来的样子。
4. **落到实惠**：学政治不为表态、不为当官，为的是看懂新闻、听懂文件、处好关系、过好日子——这与"防止政治化"的善意并不冲突。

- 引用本文只为"设定对话对手"，**不得贬低作者**；梁文的警惕心与我们的普及心，都是为普通人好。
