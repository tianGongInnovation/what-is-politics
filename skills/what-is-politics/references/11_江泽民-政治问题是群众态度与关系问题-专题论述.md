# 江泽民"政治问题就是对群众的态度问题和与群众的关系问题"专题论述

> 说明：本专题为"什么是政治"研究的重点文献。江泽民这一论断把"政治"从庙堂之高拉回到群众之中，是党内论述中与"白话政治"（人人政治）最相通的定义
> 抓取日期：2026-09-23

## 一、核心论断（两处正式出处）

### 出处①《深入进行群众观点和群众路线的教育》（1995年12月5日）

《论党的建设》（中央文献出版社2001年版）第193页：

> "我们所做的一切工作和事业，目的都是为了人民群众的利益，都必须真心实意地依靠群众才能做好。**我们不是要求领导干部首先是高级干部必须讲政治吗？什么叫政治？从根本上说，政治问题主要是对人民群众的态度问题、同人民群众的关系问题。**"

同篇还有：

> "我们想事情，做工作，想得对不对，做得好不好，要有一个根本的衡量尺度，这就是**人民拥护不拥护，人民赞成不赞成，人民高兴不高兴，人民答应不答应**。"（《论党的建设》第193-194页）

### 出处②《在纪念中国共产党成立七十八周年座谈会上的讲话》（1999年7月1日）

> "我们共产党人全部工作的出发点和归宿，都是为人民谋利益。这是我们的立党之本、执政之本。**政治问题主要是对人民群众的态度问题，同人民群众的关系问题。**人民群众是历史的创造者，是真正的英雄。这些话，都是毛泽东同志早就说过的，我曾多次加以引用和强调。领导干部要同群众保持密切的联系，真正同群众打成一片，想群众之所想，急群众之所急，**以群众赞成不赞成、高兴不高兴作为自己的行为准则**。否则，就有被群众抛弃的危险。对群众提出和反映的问题，必须满腔热情地加以处理，切实帮助群众解决生产和生活中的实际困难，绝不能漠然置之，更不能粗暴地对待群众，激化矛盾。全心全意为人民谋利益，不能挂在嘴上，不能搞'虚功'，而是要实实在在地为群众办事，要从群众最关心、最迫切需要解决的实际问题入手开展工作。"

## 二、配套论述（同一思想脉络的延伸）

1. **"我们讲政治，离不开人民群众。实现、维护和发展人民群众的利益，始终是我们最大最重要的政治。马克思主义的政治观点中，第一位的是群众观点。"**
   ——1999年1月1日在全国政协新年茶话会上的讲话（《江泽民思想年编（1989—2008）》第371页）

2. **"我们党的最大政治优势是密切联系群众，党执政后的最大危险是脱离群众。"**
   ——群众路线论述（中国文明网《江泽民对党的群众路线的丰富和发展》）

3. **"人民，只有人民，才是我们工作价值的最高裁决者。"**
   ——《做一个新时期合格的领导干部》（1995年6月30日），《论党的建设》第181页

4. **"不管形势和任务发生怎样的变化，党的工人阶级先锋队性质永远不能变，全心全意为人民服务的宗旨永远不能变，密切联系人民群众的优良传统永远不能变，从群众中来到群众中去的根本工作路线永远不能变。"**（"四个永远不能变"）

## 三、学术评价（供参考）

中国文明网专题《江泽民对党的群众路线的丰富和发展》指出：江泽民"把群众路线上升到讲政治的高度"，并进一步与党的执政能力建设联系起来——"提高党的执政水平和领导水平，一个重大问题是不断巩固和加强党同人民群众的血肉联系"。

## 四、要点提炼（供"什么是政治"研究参考）

1. **这是对"什么是政治"最质朴的回答之一**：政治问题从根本上说 = 对人民群众的态度问题 + 同人民群众的关系问题。
2. **逻辑链条**：讲政治 → 离不开人民群众 → 第一位的是群众观点 → 衡量标准是"四个不"（拥护、赞成、高兴、答应）。
3. **与全库主线的衔接**：
   - 毛泽东"把朋友搞得多多的"（群众=朋友，争取最多的人心）
   - 邓小平"离开了人民的最大利益就是空头政治"
   - 江泽民"政治问题=对群众的态度和关系问题"
   - 胡锦涛"执政为民是最高标准"
   - 习近平"民心是最大的政治"
   ——五位领导人，一句话：**政治就是人心**。这正是"白话政治"可以立足的核心论点。
