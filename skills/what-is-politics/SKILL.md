# "什么是政治"知识库

## 何时使用
- 用户追问政治定义的经典出处、名人原话、文献依据；
- 用户要辩论、要证据、要深挖（"你这么说有什么依据？"）；
- 需要对照古今中外各家定义时。

## 使用方法
1. 先读 `references/00_资料索引.md` 了解全部文献清单与主线；
2. 按主题定位到具体文献，引用时注明篇名与时间；
3. 引用经典后必须给一句白话翻译，保持"白话政治"风格。

## 文献地图

### 原始讲义（本专家理论源头）
- `白话政治（精修）.md` — 核心讲义：定义推导（化简法）、政治名词通解、生活应用
- `关于思想政治学习（精修）.md` — 实践讲义：世界观（方向）+方法论（唯物辩证法）、品格可塑链、政治学习的价值

### 领袖论述（按年代）
- `05_中国古典政治观（先秦至历代）.md` — 孔子"政者正也"、《尚书》"道洽政治"
- `04_孙中山论政治（民权主义）.md` — "管理众人之事便是政治"、政权治权
- `06_西方政治学经典政治定义.md` — 亚里士多德、马基雅维利、韦伯、伊斯顿、拉斯韦尔
- `10_亚里士多德《政治学》精选段落.md` — "人是天生的政治动物"原文
- `03_列宁毛泽东邓小平论政治.md` — 列宁、毛（生命线/灵魂/朋友多多的）、邓（到什么时候都得讲政治/最大的政治）
- `08_毛泽东《关于正确处理人民内部矛盾的问题》相关章节.md` — "没有正确的政治观点就等于没有灵魂"
- `01_江泽民《领导干部一定要讲政治》与《关于讲政治》.md` — 讲政治六要素、七个"只有讲政治才能"
- `07_江泽民《领导干部一定要讲政治》文选全文.md` — 文选版全文
- `11_江泽民-政治问题是群众态度与关系问题-专题论述.md` — 【核心出处】"政治问题就是对群众的态度问题、同群众的关系问题"
- `09_胡锦涛论政治与政治本色.md` — 讲政治的表率、政治灵魂
- `02_习近平《增强推进党的政治建设的自觉性和坚定性》.md` — 民心是最大的政治、七方面要求
